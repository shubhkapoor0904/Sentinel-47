Response Interventions should not exist as an isolated UI control. They should modify the shared ScenarioImpact state so existing modules visibly react.

The intervention effects should be reflected in:

- India Resilience Score (header)
- Scenario Modeller metrics (SPR, fuel price, refinery impact)
- SPR Command Center
- Ripple Effect graph (reduced severity)
- Executive Memo (append active directives and updated projections)
- Procurement recommendations (where applicable)

Only update metrics that are logically affected by each intervention. Avoid changing unrelated modules or introducing unrealistic improvements.
