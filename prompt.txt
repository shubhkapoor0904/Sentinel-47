UPGRADE 5 — ERROR BOUNDARIES + NETWORK FALLBACK
(demo safety net — prevents a single API failure from
crashing the entire platform mid-demo)

This is the upgrade most teams skip and most regret.

Part A — React Error Boundary (catches JS runtime errors):

  // /components/ModuleBoundary.tsx
  "use client";
  import { Component, ReactNode } from "react";

  interface Props { moduleName: string; children: ReactNode; }
  interface State { hasError: boolean; error?: Error; }

  export class ModuleBoundary extends Component<Props, State> {
    state: State = { hasError: false };

    static getDerivedStateFromError(error: Error): State {
      return { hasError: true, error };
    }

    render() {
      if (this.state.hasError) return (
        <div className="border border-orange-500/30 rounded
          p-6 font-mono text-sm">
          <p className="text-orange-500">
            ⚠ {this.props.moduleName} — MODULE FAULT
          </p>
          <p className="text-gray-400 mt-2">
            {this.state.error?.message}
          </p>
          <button
            onClick={() => this.setState({ hasError: false })}
            className="mt-4 text-teal-400 hover:underline">
            REINITIALIZE MODULE
          </button>
        </div>
      );
      return this.props.children;
    }
  }

Wrap each module view:
  <ModuleBoundary moduleName="1. GEOPOLITICAL RISK AGENT">
    <GeopoliticalRiskModule />
  </ModuleBoundary>

If Module 1 crashes, Modules 2-4 still work. The demo
continues. Judges see a "MODULE FAULT — REINITIALIZE"
button that looks intentional, not broken.

In the TanStack Query fetcher:
  queryFn: async () => {
    try {
      return await fetchRiskSignals();
    } catch {
      console.warn("News API unavailable — using fallback");
      return FALLBACK_SIGNALS;
    }
  }

Add a visible indicator when fallback is active:
  // In top strip, if using fallback data:
  <span className="text-yellow-500 text-xs font-mono">
    CACHED DATA — LIVE FEED UNAVAILABLE
  </span>

This means: if NewsAPI goes down on the venue WiFi
during your demo (very common at hackathons), the
platform shows realistic cached data and clearly
labels it, rather than showing empty panels or errors.
The demo continues. You explain it calmly. Judges see
graceful degradation, which is a senior engineering
signal.
