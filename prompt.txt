
UPGRADE 6 — URL STATE PERSISTENCE
(shareable demo links — a judge can bookmark
"localhost:3000?module=4&scenario=red_sea" and land
exactly where you want them)

npm install nuqs
(nuqs is the standard URL state library for Next.js
App Router — type-safe, server-compatible)

Replace the current active module and active scenario
state with URL-synced params:

  import { useQueryState } from "nuqs";

  // In the navigation shell:
  const [activeModule, setActiveModule] =
    useQueryState("module", {
      defaultValue: "1",
      parse: (v) => v,
    });

  // In Module 2:
  const [activeScenarioId, setActiveScenarioId] =
    useQueryState("scenario", {
      defaultValue: "",
      parse: (v) => v,
    });

Result: navigating to Module 3 with Red Sea active
produces the URL:
  ?module=3&scenario=red_sea_suspension

The guided demo tour should UPDATE the URL at each step
so the browser URL always reflects where you are. This
means:
- Pressing back/forward actually navigates between demo
  steps (or at least doesn't break them).
- You can send a judge a direct link to Module 4 with
  the Red Sea scenario pre-loaded.
- "Can you go back to the scenario screen?" during Q&A
  means clicking back, not manually re-clicking through
  4 modules.

Also add a "COPY DEMO LINK" button in the guided demo
banner that copies the current URL to clipboard — during
a live demo, if a judge wants to load it on their own
laptop, you can share the exact state in one click.
