BUG FIX: Guided demo tour caption/timer desync.

Current bug: the narration caption and step label stay frozen on
whatever step they were last (e.g. "[PROCUREMENT AGENT]") even after
navigating to a different module, and the timer (52s/90s) does not
reliably advance in sync with the active view.

Required fix:
1. The caption, step label, and timer must always derive from a single
   shared "current demo step" state — never let the caption text be
   independently stale from the view that's showing.
2. If the user manually navigates away during an active guided tour,
   either (a) pause the timer and caption together, clearly showing
   "PAUSED" in the banner, or (b) jump the caption/timer to match
   wherever the user navigated. Pick (a) — pausing both together is
   safer and avoids any mismatch.
3. "RESUME" must continue the timer and caption from the correct
   paused step, not restart or skip.
4. Add a simple console log or visible debug state (current step index,
   timer value) so this is easy to verify before demo day.

Test explicitly: start tour, manually click to a different module
mid-tour, confirm caption+timer pause together, click RESUME, confirm
they resume in sync.
