Create /store/sentinel.ts with a single Zustand store.
This store is the ONLY source of truth for shared state
across all 4 modules. Do not leave any of this state in

interface SentinelStore {

  // Module 1 live state
  brentPrice: number;
  corridorScores: {
    hormuz: number;
    redSea: number;
    suez: number;
  };
  signals: Signal[];         // live threat signal feed
  darkFleetEvents: DarkFleetEntry[];
  lastFetchedAt: Date | null;

  // Module 2 scenario state
  activeScenarioId: string | null;
  scenarioOutput: ScenarioOutput | null;

  // Module 3 procurement state
  rankedOptions: ProcurementOption[];

  // Module 4 memo state
  currentMemo: Memo | null;
  ledgerEntries: LedgerEntry[];

  // Resilience Index (derived, auto-computed)
  resilienceScore: number;

  // Guided demo state
  demoRunning: boolean;
  demoPaused: boolean;
  demoStep: number;          // 0 = not started, 1-4 = active step
  demoStepStartedAt: Date | null;

  // Actions
  setCorridorScores: (scores) => void;
  setActiveScenario: (id: string) => void;
  appendLedgerEntry: (entry: LedgerEntry) => void;
  setDemoStep: (step: number) => void;
  pauseDemo: () => void;
  resumeDemo: () => void;
  stopDemo: () => void;
}

CRITICAL RULES:
- resilienceScore must be a COMPUTED value, not stored
  directly — derive it inside the store from corridorScores
  + scenarioOutput every time either changes. Use Zustand's
  subscribeWithSelector or a derived selector for this.
  Never let resilienceScore get out of sync with its inputs.
- demoStep must be the single source of truth for the
  guided tour caption, the timer display, and the
  auto-navigation. Any component that reads demoStep
  will automatically stay in sync — the caption desync
  bug becomes structurally impossible.
- LedgerEntry must be appended to localStorage on every
  appendLedgerEntry call (see Upgrade 2 below) — wire
  this in the action, not in the component.
