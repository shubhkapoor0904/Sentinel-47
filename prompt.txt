Wire the following into the appendLedgerEntry store action:

interface LedgerEntry {
  id: string;               // crypto.randomUUID()
  sequence: number;         // monotonically incrementing
  timestamp: string;        // ISO 8601, IST timezone
  scenarioId: string;
  corridorScores: object;   // snapshot of live state
  memoSubject: string;
  contentHash: string;      // SHA-256 of full memo text
  previousHash: string;     // SHA-256 of previous entry's
                            // contentHash — chain structure
}

Computing contentHash:
  const encoder = new TextEncoder();
  const data = encoder.encode(memoFullText + timestamp);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const contentHash = hashArray.map(b =>
    b.toString(16).padStart(2, '0')).join('');

Computing previousHash:
  If ledger is empty, previousHash = "GENESIS"
  Otherwise previousHash = ledgerEntries[last].contentHash

Persistence:

  full entries array to localStorage under the key
  "sentinel47_ledger". On store initialization, read from
  localStorage and hydrate ledgerEntries — the ledger
  survives browser refresh and tab close.

  const stored = localStorage.getItem("sentinel47_ledger");
  if (stored) ledgerEntries = JSON.parse(stored);
